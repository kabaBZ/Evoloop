# Security

Do not open a public issue for a security problem.

Report it privately to `{{PRIVATE_SECURITY_CHANNEL}}`. Include:

- the version, platform and surface where it happens;
- what an attacker can do, and what they need to start;
- the smallest reproduction you have;
- whether the problem is already public anywhere.

Do not include live credentials, other users' data or a working exploit against
a service you do not own.

We aim to acknowledge a report within a few days and to agree on a disclosure
date before anything is published. A fix ships as a normal release; the
release notes name the issue only once the fixed version is downloadable.
